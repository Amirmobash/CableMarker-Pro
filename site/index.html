ESP32 · laser distance · servo marker

Measure long cable or pipe runs. Mark the right position.

CableMarker Pro is an ESP32 controller for laser-assisted distance measurement and physical marking. It is designed for workshop workflows that can extend to about 100 m when paired with a rangefinder rated for the job.

Built around a real marking workflow

CableMarker Pro combines live distance measurement, a servo-driven marker, an external trigger and a local web dashboard. The firmware keeps the original project wiring but replaces long blocking operations with state-based control so the device remains responsive while marking.

Measure

Read a UART laser sensor, validate its frame and apply the mechanical calibration offset.

Mark

Run one controlled servo marking cycle with cooldown protection and buzzer feedback.

Operate locally

Connect directly to the ESP32 access point. No cloud account or internet connection is required.

About the 100 m claim: the software supports 100,000 mm easily, but optical range and accuracy depend on the actual rangefinder, target surface, alignment and environment. CableMarker Pro does not turn a short-range sensor into a 100 m sensor.

Engineering details, not marketing filler

The repository documents the ESP32 pinout, laser protocol assumptions, calibration method, servo power concerns, external trigger behavior, JSON API and troubleshooting steps in both English and German.
